### Automated Optimization Options

#### Option 1: Use Next.js Image Optimization (Already Enabled)
The site is already configured to serve images in WebP/AVIF format automatically through Next.js Image component. However, **source files should still be optimized**.

#### Option 2: Batch Processing Script
Create a script to optimize all images at once:

```bash
# Install sharp-cli globally
npm install -g sharp-cli

# Optimize all JPGs
find ./public/images -name "*.jpg" -o -name "*.jpeg" | xargs -I {} sharp {} -o {} --quality 80

# Convert PNGs to WebP
find ./public/images -name "*.png" | while read file; do
  sharp "$file" --webp --quality 85 -o "${file%.png}.webp"
done
```
